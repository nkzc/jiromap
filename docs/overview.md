# 二郎マップ — システム概要

**本番 URL**: https://jiromap.pages.dev

---

## このサービスは何をするのか

ユーザーの現在地周辺にある**二郎系ラーメン店**を地図上に表示し、
「今何人並んでいるか」をユーザー同士で投稿・共有できる Web サービス。
Google AdSense による広告収益化が目的。

---

## 画面構成

```
/ （トップ・地図）
│   現在地周辺の店舗をピン表示
│   ピンをタップ → 店舗カード（混雑状況・投稿ボタン）
│   30秒ごとに自動更新
│
├── /shops （店舗一覧）
│       距離順リスト、5件ごとに広告
│
├── /shops/[id] （店舗詳細）
│       混雑状況・営業時間・投稿フォーム
│       JSON-LD 構造化データ（SEO）
│
├── /privacy （プライバシーポリシー）
├── /terms （利用規約）
└── /sitemap.xml （動的サイトマップ）
```

## 混雑投稿から表示されるまでの流れ

```
1. ユーザーが「6〜10人」を選んで投稿
        ↓
2. POST /api/shops/1/reports
        ↓
3. API が処理:
   ① IP を SHA-256 でハッシュ化（生IPは保存しない）
   ② セッション Cookie を確認（なければ新規発行）
   ③ KV でスパムチェック（30分以内に同店舗へ投稿済みなら 429）
   ④ D1 の crowd_reports に INSERT
   ⑤ KV にスパムブロック情報を書き込み（30分間有効）
   ⑥ KV のステータスキャッシュを削除
        ↓
4. 201 レスポンス（最新ステータスを即時返却 → UI がすぐ更新される）
        ↓
5. 最大1分後: Cron Worker がバッチ集計
   ① 直近30分の投稿を集計（Window 関数で最頻値を計算）
   ② shop_statuses を更新
   ③ KV に結果をキャッシュ（90秒間有効）
        ↓
6. 他のユーザーが30秒ポーリングでステータスを取得
   → KV ヒット（高速）→ 混雑情報が表示される
```

## 混雑レベルの定義

| レベル | 色 | 意味 |
|-------|---|------|
| 0 | 🟢 緑 | 並びなし |
| 1 | 🟡 黄緑 | 1〜5人 |
| 2 | 🟡 黄 | 6〜10人 |
| 3 | 🟠 橙 | 11人以上 |
| 4 | 🔴 赤 | 麺切れ/臨時休業 |
| null | ⚪ 灰 | 情報なし（30分以内の投稿なし） |

## スパム対策の仕組み

```
投稿リクエスト受信
      │
      ├─ KV: spam:session:{uuid}:shop:{id} が存在する？
      │        YES → 429 (30分以内に投稿済み)
      │
      ├─ KV: spam:ip:{sha256}:shop:{id} が存在する？
      │        YES → 429 (同じIPから投稿済み)
      │
      ├─ KV が使えない場合 → D1 でフォールバックチェック
      │
      └─ 全クリア → 投稿を保存
```

- **生 IP は一切保存しない**（SHA-256 + ソルトでハッシュ化）
- ソルト（`IP_HASH_SALT`）は Cloudflare Secrets に保存（コードに書かない）

## インフラコスト

| サービス | 無料枠 | 現在の使用量（目安） |
|---------|------|----------------|
| Cloudflare Pages | 帯域無制限 | — |
| Cloudflare Workers | 100,000 req/日 | DAU100 規模で約24% |
| Cloudflare D1 | 5GB | 現在 0.07MB（余裕あり） |
| Cloudflare KV | 1,000 write/日 | 差分チェックで大幅節約 |
| OpenStreetMap タイル | 無料（重負荷は要注意） | DAU100 では問題なし |

**現在の月額コスト: 0円**

DAU が 500 を超えたら Cloudflare Workers Paid（$5/月）への移行を検討。
