# 二郎マップ — システム概要

**本番 URL**: https://jiromap.pages.dev

---

## このサービスは何をするのか

ユーザーの現在地周辺にある**二郎系ラーメン店**を地図上に表示し、
「今何人並んでいるか」をユーザー同士で投稿・共有できる Web サービス。
Google AdSense による広告収益化が目的。

---

## 画面構成

```
/ （トップ・ランディングページ）
│   二郎解説・ニンニク文化・機能説明などコンテンツ重視の構成
│   地図へのCTAボタン（「地図を見る」/「View Map」）を配置
│
├── /map （地図ページ）
│   現在地周辺の店舗をピン表示
│   ピンをタップ → 店舗カード（混雑状況・ルートを見る）
│   30秒ごとに自動更新（GPS モード時は位置情報も更新）
│   マップ下部スライダーで検索範囲を変更（5〜50km・5km刻み・デフォルト20km）
│   右上ボタンで「現在地」/「地図中心」モード切替
│     現在地モード: GPS 位置を基準に検索
│     地図中心モード: 地図をスクロールするとその中心から検索
│
├── /shops （店舗一覧）
│       距離順リスト、5件ごとに広告
│       ヘッダーに現在の検索範囲（例: 20km圏内）を表示
│
├── /shops/[id] （店舗詳細）
│       混雑状況・営業時間・投稿フォーム
│       JSON-LD 構造化データ（SEO）
│
├── /guide （初心者向けガイド）
│       二郎系ラーメンの頼み方・マナー・初心者アドバイス（5セクション構成）
│       免責事項あり・バージョン管理あり・日英対応
│
├── /glossary （二郎用語集）
│       二郎系ラーメン特有の用語を13語収録・日英対応
│       フッターからリンク
│
├── /about （サービスについて）
│       制作背景（4つの動機）中心の構成
│       フッターからリンク
│
├── /contact （お問い合わせ）
│       メールアドレス掲載・日英両対応
├── /privacy （プライバシーポリシー）
├── /terms （利用規約）
└── /sitemap.xml （動的サイトマップ・/map・/en/map・/about・/shops 等を含む）
```

## ステータス表示の流れ

> 注意: 混雑投稿フォーム（POST /api/shops/:id/reports）は UI・API ともに削除済み（ReportForm.svelte 削除）。
> 以下は現在の「読み取り専用」フローを示す。

```
1. Cron Worker が1分ごとにバッチ集計
   ① 直近30分の crowd_reports を集計（Window 関数で最頻値を計算）
   ② shop_statuses を upsert
   ③ KV に結果をキャッシュ（90秒間有効）
        ↓
2. ユーザーが30秒ポーリングでステータスを取得
   GET /api/shops/:id/status
   → KV ヒット（高速）→ 混雑情報が表示される
   → KV ミス → D1 shop_statuses からフォールバック
```

## 混雑レベルの定義

| レベル | 色 | 意味 |
|-------|---|------|
| 0 | 🟢 緑 | 並びなし |
| 1 | 🟡 黄緑 | 1〜5人 |
| 2 | 🟡 黄 | 6〜10人 |
| 3 | 🟠 橙 | 11人以上 |
| 4 | 🔴 赤 | 麺切れ/臨時休業 |
| null | ⚪ 灰 | 情報なし（30分以内の投稿なし） |

## スパム対策の仕組み

```
投稿リクエスト受信
      │
      ├─ KV: spam:session:{uuid}:shop:{id} が存在する？
      │        YES → 429 (30分以内に投稿済み)
      │
      ├─ KV: spam:ip:{sha256}:shop:{id} が存在する？
      │        YES → 429 (同じIPから投稿済み)
      │
      ├─ KV が使えない場合 → D1 でフォールバックチェック
      │
      └─ 全クリア → 投稿を保存
```

- **生 IP は一切保存しない**（SHA-256 + ソルトでハッシュ化）
- ソルト（`IP_HASH_SALT`）は Cloudflare Secrets に保存（コードに書かない）

## インフラコスト

| サービス | 無料枠 | 現在の使用量（目安） |
|---------|------|----------------|
| Cloudflare Pages | 帯域無制限 | — |
| Cloudflare Workers | 100,000 req/日 | DAU100 規模で約24% |
| Cloudflare D1 | 5GB | 現在 0.07MB（余裕あり） |
| Cloudflare KV | 1,000 write/日 | 差分チェックで大幅節約 |
| OpenStreetMap タイル | 無料（重負荷は要注意） | DAU100 では問題なし |

**現在の月額コスト: 0円**

DAU が 500 を超えたら Cloudflare Workers Paid（$5/月）への移行を検討。
