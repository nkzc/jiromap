# frontend エージェント指示書

## あなたの役割
二郎マップのフロントエンドを実装する。
地図 UI・店舗カード・混雑投稿フォーム・広告配置・モバイル対応を担当する。

## 作業開始前の確認事項
1. `CLAUDE.md` を Read tool で読み、プロジェクト原則を把握すること
2. 本ファイル（agents/frontend.md）を全て読んでから作業を開始すること
3. `docs/adr/ADR-001-stack-selection.md` を読み、採用スタックを確認すること
4. スタック未確定の場合はリーダーに確認を求め、作業を開始しないこと

## 実装すべき画面・コンポーネント

### 1. メイン地図画面（/）
- Geolocation API で現在地を取得し、周辺の二郎系店舗をピンで表示する
- ピンの色・アイコンで混雑度を表現する（空き=緑、やや混雑=黄、混雑=赤）
- ピンタップで店舗カードをポップアップ表示する
- 「現在地に戻る」ボタンを地図上に配置する

### 2. 店舗カード（ポップアップ）
- 店舗名・住所・営業時間・定休日
- 現在の混雑状況（最終投稿時刻付き）
- 「並び報告する」ボタン（投稿フォームに遷移またはモーダル）
- 食べログ・ぐるなびへのアフィリエイトリンクボタン（「PR」表記必須）
- 「地図アプリで開く」ボタン（Google Maps / Apple Maps ディープリンク）

### 3. 混雑報告フォーム
- 並び人数をタップ選択（0人・1〜5人・6〜10人・10人以上）
- 待ち時間（任意入力、分単位）
- 送信後に「ありがとうございます」フィードバック表示

### 4. 店舗一覧（/shops）
- 現在地から近い順に店舗をリスト表示
- 各行に混雑アイコンと距離を表示
- AdSense ディスプレイ広告枠を 5 件ごとの間に配置（インフィード）

### 5. 店舗詳細（/shops/[id]）
- 全店舗情報の表示
- 混雑履歴グラフ（直近 24 時間）
- Amazon アソシエイトリンク（二郎グッズ・トッピング関連、「PR」表記必須）
- 食べログ・ぐるなびリンク（アフィリエイト、「PR」表記必須）
- OGP・構造化データは seo_monetize エージェントと連携すること

## 広告配置ルール
- AdSense の自動広告を基本とするが、以下の位置に手動広告枠を用意する
  - 店舗一覧の 5 件ごとの間（インフィード広告）
  - 店舗詳細ページの本文下（ディスプレイ広告）
- 地図上に広告を重ねる配置は禁止（UX 破壊・AdSense ポリシー違反のリスク）
- 広告ロード前にレイアウトシフトが起きないよう、広告枠に固定サイズを設定すること

## UI/UX の原則
- **モバイルファースト** — スマートフォン（375px 幅）での利用が主体
- Tailwind CSS を推奨（採用スタックに依存）
- ダークモード対応は V2 以降（今は不要）
- アクセシビリティ: `alt` 属性・`aria-label` の基本対応は必須

## 実装上の制約
- 環境変数は `.env.local` に格納し、`NEXT_PUBLIC_` prefix の公開範囲に注意すること
- 地図ライブラリは architect の ADR に従うこと（無断で変更しない）
- 無駄な API 呼び出しをしないこと（マーカー描画のたびにリクエストしない等）
- ページ離脱時に Geolocation `watchPosition` を必ず停止すること

- `src/README.md` または `src/frontend/README.md` にローカル起動手順を記載する
